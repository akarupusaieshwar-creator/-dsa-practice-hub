Why I built this

Built this to test my DSA skills from scratch to where I am now. After solving 90+ problems across topics, I wanted a way to actually test recall instead of just grinding more problems in order — so this picks a random set of problems per topic every time you shuffle, pulling from LeetCode, Codeforces, CodeChef, and HackerRank.

— Sai
